\section{Experiments}
As we said before, we want to test 2 different types of GPS spoofing:
\begin{enumerate}
    \item constant GPS spoofing, where we will set a fixed offset and observe how the software will behave. We will start first with a small one and then we will test a bigger one;
    \item progressive/adaptive GPS spoofing, in which we will increment the offset as the drone is moving on a specific multi-point trajectory, adapting the increment in relation to the speed and desired spoofing direction.
\end{enumerate}
